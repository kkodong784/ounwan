# ownwan (오운완)

## 서비스 소개 
오운완은 자신의 운동 및 식사 기록을 관리하고, 
자신의 습관을 돌아보고 싶은 사용자를 위한 서비스 입니다. 

사용자는 운동 및 식사 기록을 남기고,
기록을 바탕으로 AI 피드백을 받아 개선 방향을 탐색할 수 있습니다. <br>
다른 사용자와 자신의 기록을 공유하는 기능도 제공할 예정입니다.

- 개발 기간: 2026.07 ~ 진행 중 
- 개발 형태: 개인 프로젝트 
- 서비스 주소: 추후 작성 예정 

## 주요 기능 

### 1. 운동 기록 관리
- 자신이 수행한 운동을 기록합니다.
- 저장한 운동 기록을 조회합니다.

### 2. 식사 기록 관리
- 자신이 먹은 식사를 기록합니다.
- 저장한 식사 기록을 조회합니다.

### 3. AI 피드백
- 운동 및 식사 기록을 바탕으로 피드백을 받습니다.
- 피드백을 참고해 자신의 운동·식사 습관을 돌아봅니다.

### 4. 기록 공유
- 다른 사용자에게 자신의 기록을 공유합니다.
- 공유 범위와 공개 방식은 추후 결정합니다.
