# 기능 요구사항 

## 1. 기능 목록 

| 기능 ID | 기능명   | 설명         |
|---------|----------|--------------|
| F-01    | 운동 기록 작성  | 사용자는 자신이 한 운동을 기록할 수 있다.  |
| F-02    | 운동 기록 조회 | 사용자는 날짜별로 자신이 한 운동을 조회할 수 있다. |

## 2. 공통 정책  

### 로그인 관련 규칙 
- 운동 및 식사 기록 작성, 조회, 수정, 삭제는 로그인한 사용자만 이용할 수 있다. 
- AI 피드백 요청은 로그인한 사용자만 사용할 수 있다. 

### 데이터 접근 권한 
- 운동, 식사 기록의 작성자는 로그인한 사용자로 지정한다. 
- 운동, 식사 기록의 공유 범위는 사용자가 직접 공개/비공개로 지정한다. 

### 날짜와 시간 기준 
- 날짜와 시간은 한국 시간(Asia/Seoul)을 기준으로 판단한다. 
- 사용자가 입력한 운동·식사 날짜와 실제 기록 등록 시각은 구분한다. 

## 3. 기능 상세 

### F-01. 운동 기록 작성 

#### 목적 
사용자는 운동 유형에 맞는 정보를 입력하여 자신이 한 운동을 기록할 수 있다.

#### 사용 조건 
- 사용 가능한 사용자: 로그인 한 사용자 
- 로그인 필요 여부: 필요

#### 입력 정보

공통 입력 정보:

| 항목      | 필수 여부 | 허용 조건           | 예시                                           |
|-----------|-----------|---------------------|------------------------------------------------|
| 운동 유형 | 필수      | 근력 운동 또는 러닝 | 근력 운동                                      |
| 운동 날짜 | 필수      | 오늘 또는 과거 날짜 | 2026-10-26                                     |
| 운동 메모 | 선택      | 최대 500자          | 오늘 컨티션이 좋아서 평소보다 한 세트 더 했다. |

근력 운동 선택 시:

| 항목                   | 필수 여부 | 허용 조건                    | 예시   |
|------------------------|-----------|------------------------------|--------|
| 운동 종목              | 필수      | 운동 종목 선택               | 스쿼트 |
| 세트별 반복 횟수(reps) | 필수      | 각 세트에 1 이상의 정수 입력 | 10회   |
| 세트별 중량(kg)        | 필수      | 0이상의 소수 입력            | 40kg   |

러닝 선택 시:

| 항목         | 필수 여부 | 허용 조건                      | 예시     |
|--------------|-----------|--------------------------------|----------|
| 거리(km)     | 필수      | 0이상의 소수                   | 5km      |
| 총 러닝 시간 | 필수      | 시·분·초로 입력, 총합 0초 초과 | 00:30:00 |
