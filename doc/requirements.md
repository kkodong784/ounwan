## 2. 공통 정책 

### 로그인 관련 규칙 
- 운동 및 식사 기록 작성, 조회, 수정, 삭제는 로그인한 사용자만 이용할 수 있다. 
- AI 피드백 요청은 로그인한 사용자만 사용할 수 있다. 

### 데이터 접근 권한 
- 운동, 식사 기록의 작성자는 로그인한 사용자로 지정한다. 
- 운동, 식사 기록의 공유 범위는 사용자가 직접 공개/비공개로 지정한다. ⭐ 입력 정보에 추가 필요!(공개, 비공개)

### 날짜와 시간 기준 
- 날짜와 시간은 한국 시간(Asia/Seoul)을 기준으로 판단한다. 
- 사용자가 입력한 운동·식사 날짜와 실제 기록 등록 시각은 구분한다. 

## 3. 기능 상세 

### F-01. 운동 기록 작성 

#### 목적 
사용자는 운동 유형에 맞는 정보를 입력하여 자신이 한 운동을 기록할 수 있다.

#### 사용 조건 
- 사용 가능한 사용자: 로그인 한 사용자 
- 로그인 필요 여부: 필요 

#### 입력 정보 

공통 입력 정보: 

| 항목      | 필수 여부 | 허용 조건           | 예시                                           |
|-----------|-----------|---------------------|------------------------------------------------|
| 운동 유형 | 필수      | 근력 운동 또는 러닝 | 근력 운동                                      |
| 운동 날짜 | 필수      | 오늘 또는 과거 날짜 | 2026-10-26                                     |
| 운동 메모 | 선택      | 최대 500자          | 오늘 컨티션이 좋아서 평소보다 한 세트 더 했다. |

근력 운동 선택 시: 

| 항목                   | 필수 여부 | 허용 조건                       | 예시   |
|------------------------|-----------|---------------------------------|--------|
| 운동 종목              | 필수      | 운동 종목 선택                  | 스쿼트 |
| 세트별 반복 횟수(reps) | 필수      | 각 세트에 1 이상의 정수 입력    | 10회   |
| 세트별 중량(kg)        | 선택      | 입력 시 0이상의 숫사(소수 허용) | 40kg   |

러닝 선택 시: 

| 항목         | 필수 여부 | 허용 조건                      | 예시     |
|--------------|-----------|--------------------------------|----------|
| 거리(km)     | 필수      | 0보다 큰 숫자(소수 혀용)       | 5km      |
| 총 러닝 시간 | 필수      | 시·분·초로 입력, 총합 0초 초과 | 00:30:00 |


#### 기본 동작 
1. 사용자가 운동 기록 작성 화면에 들어간다. 
2. 근력 운동 또는 러닝을 선택한다. 
3. 서비스는 선택한 유형에 맞는 입력 항목을 보여준다. 
4. 사용자가 운동 정보를 입력하고 저장 버튼을 누른다.
5. 서비스는 공통 조건과 해당 운동 유형의 입력 조건을 확인한다.
6. 조건을 충족하면 기록을 저장하고 상세 화면으로 이동한다. 

#### 동작 규칙 
- 작성자는 로그인한 사용자로 지정한다. 
- 하나의 기록에는 하나의 운동 유형을 적용한다.
- 같은 날짜에 근력 운동과 러닝 기록을 각각 작성할 수 있다.
- 날짜 판단은 한국 시간(Asia/Seoul)을 기준으로 한다. 

근력 운동: 
- 하나의 기록에 하나의 운동 종목을 기록한다. 
- 세트는 최소 1개 이상 입력한다. 
- 각 세트의 반복 횟수와 중량을 따로 기록할 수 있다. 
- 전체 세트 수는 입력된 세트 개수로 계산한다. 
- 맨몸 운동도 기록할 수 있도록 중량은 선택 입력으로 한다. 

러닝: 
- 거리와 총 러닝 시간을 모두 입력해야한다. 
- 평균 페이스는 총 러닝 시간을 거리로 나누어 자동 계산한다. 
- 평균 페이스는 1km당 소요 시간인 분:초/km로 표시한다. 
- 페이스의 초 단위는 반올림한다. 

#### 성공 결과 
- 저장되거나 변경되는 정보: 
  - 공통 정보와 선택한 운동 유형의 상세 정보 
  - 작성자, 기록 식별자, 작성 일시 
- 사용자에게 보여줄 결과: 
  - 저장 완료 메시지와 기록 상세 화면
  - 근력 운동은 세트별 반복 횟수와 중량 
  - 러닝은 거리, 총 러닝 시간, 계산된 평균 페이스

#### 실패 상황 

| 상황                                         | 서비스의 처리                         |
|----------------------------------------------|---------------------------------------|
| 로그인하지 않음                              | 저장 요청을 거부하고 로그인 필요 안내 |
| 공통 필수 항목 누락                          | 저장하지 않고 누락 항목 안내          |
| 근력 운동의 세트가 없거나 반복 횟수가 잘못됨 | 저장하지 않고 해당 입력 조건 안내     |
| 러닝 거리나 시간이 0 이하임                  | 저장하지 않고 0보다 큰 값 입력 안내   |
| 서버 문제로 저장 실패                        | 입력 내용을 유지하고 재시도 안내      |

#### 완료 확인 
아래 항목이 충족되면 기능 구현이 완료된 것으로 판단한다.

- [ ] 로그인한 사용자만 기록을 저장할 수 있다.
- [ ] 공통 필수 항목과 유형별 필수 항목을 검사한다.
- [ ] 근력 운동은 세트별로 서로 다른 반복 횟수와 중량을 저장할 수 있다.
- [ ] 근력 운동은 세트가 없으면 저장할 수 없다.
- [ ] 러닝 5km, 30분 입력 시 평균 페이스가 6:00/km로 표시된다.
- [ ] 러닝 거리가 0이면 저장하지 않는다.
- [ ] 저장 성공 후 작성한 기록의 상세 화면으로 이동한다.

#### 목적 
사용자는 원하는 날짜의 운동 기록을 조회할 수 있다. 

#### 사용 조건 
- 사용 가능한 사용자: 로그인 한 사용자 
- 로그인 필요 여부: 필요 

#### 입력 정보 
| 항목         | 필수 여부 | 허용조건            | 예시       |
|--------------|-----------|---------------------|------------|
| 운동 날짜    | 필수      | 오늘 또는 과거 날짜 | 2026-10-26 |
| 운동 기록 id | 선택      | 1이상의 정수        | 50         |


#### 기본 동작 
1. 사용자가 운동 기록 조회 작성 화면에 들어간다. 
2. 사용자는 운동 날짜, 운동 기록id(선택)를 입력한다. 
3. 서비스는 사용자가 입력한 운동 날짜, 운동 기록 id에 따라서 운동 기록을 보여준다.

#### 동작 규칙 
- 사용자 자신이 작성한 운동 기록만 조회할 수 있다.

#### 성공 결과
- 사용자에게 보여줄 결과:
  - 운동 날짜만 입력한 경우: 입력된 운동 날짜에 해당하는 전체 운동 기록의 운동 메모, 운동 종목, 세트별 반복 횟수, 세트별 중량

#### 실패 상황
| 상황                | 서비스의 처리                         |
|---------------------|---------------------------------------|

| 운동 날짜 항목 누락 | 저장하지 않고 누락 항목 안내          |
